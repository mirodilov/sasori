# Sasori

Android-приложение для удалённого управления телефоном через Telegram-бота.

Сайт: [sasori.xops.uz](https://sasori.xops.uz) · Telegram: [@the_hikiman](https://t.me/the_hikiman)

## Возможности

- 📩 **SMS** — входящие/исходящие, история, ответы из Telegram
- 📞 **Звонки** — история, исходящий вызов по команде, выбор SIM
- 📸 **Камера** — снимок без сохранения в галерею
- 🖼 **Галерея** — просмотр альбомов, скачивание фото
- 📍 **Геолокация** — текущие координаты телефона
- 📁 **Файлы** — список, скачивание, загрузка, удаление
- 🔔 **Уведомления** — пересылка уведомлений приложений в Telegram
- 🔋 **Система** — батарея, info об устройстве, список приложений, режим звонка
- 👤 **Контакты** и **USSD**

## Быстрый старт

1. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. Узнайте свой Chat ID (например, через [@userinfobot](https://t.me/userinfobot)).
3. Установите APK, откройте **Sasori**.
4. Вставьте **Bot Token** и **Chat ID**, включите переключатель.
5. Выдайте необходимые разрешения (SMS, звонки, камера, геолокация, файлы, уведомления).

## Основные команды

| Команда | Описание |
|--------|----------|
| `/help` | Список всех команд |
| `/sms day\|week\|month` | История SMS |
| `/calls day\|week\|month` | История звонков |
| `/call +7900…` | Исходящий звонок |
| `/camera` | Снимок с камеры |
| `/photos` / `/album Camera` | Галерея |
| `/location` | Геолокация |
| `/ls` / `/get_file` | Файлы |
| `/forward_notify all\|selected\|none` | Пересылка уведомлений |
| `/battery` | Уровень батареи |
| `/system_info` | Информация об устройстве |
| `/sims` / `/sim1` / `/sim2` | Управление SIM |

Ответ на SMS: reply на сообщение «📩 Новое SMS» или формат `+79001234567 текст`.

## Требования

- Android 7.0+
- Telegram-бот и личный Chat ID
- Разрешения: SMS, Phone, Contacts, Camera, Location, Storage, Notification access
